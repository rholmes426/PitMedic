# PitMedic chat transcripts

This directory is reserved for conversation exports used as project context for other
assistants. Verbatim exports should be stored unchanged, with a date and source in the
filename, for example `2026-09-19-chatgpt-export.json`.

The Codex runtime can see project history summaries and selected messages, but it does
not provide the complete raw ChatGPT transcript as a file. Therefore this repository
currently contains an index/summary, not a complete verbatim transcript export. Do not
describe the summary as a full transcript. Add the original export here if the user
downloads one from ChatGPT.
