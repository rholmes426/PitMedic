Startup, rendering, or sustained load

Start with the moment it failed.

Startup, rendering, and load failures leave different evidence behind. Pick the closest point below to focus the investigation.

Startup

At startup

The simulator closes before reaching the main menu. Unreal Engine evidence, saved configuration, runtime components, and graphics initialization become the first places to look.

Rendering

With a rendering error

Messages such as a lost or hung graphics device make the driver timeline, overlays, GPU behavior, and system stability especially important.

Sustained load

Under sustained load

A failure that appears only after racing for a while raises different questions: temperature trends, memory use, driver resets, and unstable hardware settings.
