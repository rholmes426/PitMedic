Diagnostic guidance

Assetto Corsa EVO

SimPro startup conflicts and RaceHub display data

SIMAGIC documented an EVO startup/crash conflict with SimPro 3 in the older 3.0.3 release (May 7, 2026). Check the installed generation and current supported update. RaceHub 4.5.1 fixes EVO DRS data and uses core tyre temperature to match the simulator. Update the relevant vendor app manually and retest; these symptoms alone do not justify deleting EVO profiles.

Guided diagnosisGuidanceEvidence reviewed 2026-10-05Guide updated 2026-10-05

Checks and expected results

Check which companion app is running and distinguish an EVO startup failure from incorrect peripheral display data.

Before you repair it

  • Record the EVO build, installed SimPro or RaceHub version, and whether the problem concerns startup or only peripheral data.
  • Review vendor hardware compatibility and the supported update path; never interrupt firmware flashing.
  • Retest the same launch or DRS/temperature display after the vendor update. Preserve settings and captured faults.

How to confirm the result

Repeat the affected scenario after the supported update or reversible check. If it persists, preserve logs and contact the relevant vendor; this guide does not promise a successful repair.

Repair limits and when to stop

Guidance only. PitMedic does not update vendor software, flash firmware, delete profiles or change these settings automatically. An unknown version or generic failure is not proof of a match.
