iRacing UI stuck on Welcome to iRacing

An iRacing UI that remains on Welcome to iRacing can be tested with the supported UISafe setting when that setting is present.

Automatic repair availableActiveEvidence reviewed 2026-09-01Guide updated 2026-09-29

Checks and expected results

Before you repair it

  • Confirm the UI stops at Welcome to iRacing and finish any active update.
  • With iRacing closed, locate app.ini in the actual Documents\iRacing folder and preserve a backup.
  • Check whether UISafe exists and is set to 1 before using the targeted change to 0.

How to confirm the result

Relaunch the UI. It should progress beyond the welcome screen; if there is no improvement, restore the saved setting and retain the UI log.

Repair limits and when to stop

This changes one setting. Do not invent the setting when absent or treat every startup crash as this issue; no full Documents-folder reset is needed for this test.

How PitMedic recognizes it

UI startup stuck/crashing with the supported UISafe setting present in app.ini.

Signals PitMedic may recognize

  • Welcome to iRacing
  • UISafe

Built-in response

Back up app.ini and change UISafe from 1 to 0, then relaunch; restore if ineffective.
