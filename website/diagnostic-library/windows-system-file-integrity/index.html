Windows repair

Windows

Repair confirmed Windows component or system file corruption

If checks identify damaged Windows components or protected files, the Windows servicing tools can attempt recovery.

Approval requiredActiveEvidence reviewed 2026-11-26Guide updated 2026-11-26

Checks and expected results

PitMedic requests DISM RestoreHealth and SFC scannow with approval, capturing their exit status and output.

Before you repair it

  • Review the Windows integrity check output or other corroborated evidence first.
  • Close running simulators, allow servicing and updates to finish, and approve the time estimate.

How to confirm the result

Review Windows results and restart if required. Repeat the same original symptom. If the component store lacks repair source files, use supported Windows repair guidance.

Repair limits and when to stop

Windows servicing is system-wide and can require repair downloads or a reboot. The records do not constitute a restorable copy of Windows. A successful command is distinct from a resolved application fault.

When to use this check

Request Windows system repair after reviewing a Windows integrity check or other corroborated evidence of component or protected-file corruption.

Built-in response

After approval, execute DISM RestoreHealth followed by SFC scannow using the built-in Windows tools. Preserve their output and exit status, then restart if required and retest the original symptom.
