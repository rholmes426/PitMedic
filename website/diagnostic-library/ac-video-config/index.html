Assetto Corsa

Original Assetto Corsa display configuration recovery

For the original Assetto Corsa, PitMedic can preserve and reset only the user video.ini when display settings prevent a session from opening correctly.

Approval requiredActiveEvidence reviewed 2026-11-17Guide updated 2026-11-17

Checks and expected results

This is a targeted configuration test supported by community reports. It does not diagnose every black screen, driver failure or CSP/mod problem.

Before you repair it

  • Test a stock car and stock track first. Record the monitor layout, resolution and VR mode before resetting.
  • Close acs.exe/acs_x86.exe, the AssettoCorsa launcher and Content Manager so they cannot overwrite the configuration.
  • In the Assetto Corsa page, select Repair Tools and review the display-settings repair. Display preferences may need reconfiguration.

How to confirm the result

Start AC, choose the correct resolution/display mode and test a stock session. If ineffective, close AC and Content Manager, choose the same repair and Restore last backup. Current settings are preserved before restoring.

Repair limits and when to stop

Requires PitMedic 1.0.0.13 or later. Preserves cfg/video.ini only; installation defaults, controls, presets, setups, mods, CSP and Content Manager settings are not reset. File-operation tests do not establish live gameplay success.

How PitMedic recognizes it

An exact current-session video.ini failure, or an explicit display-symptom selection in Repair Tools. Normal INI dumps and generic crashes do not select this repair.

Built-in response

After consent and with the simulator, launcher and Content Manager closed, preserve only Documents/Assetto Corsa/cfg/video.ini and remove its active copy. Let AC rebuild display settings. Retest a stock car and track; Restore last backup preserves the new configuration before restoring the original.

Repair safetyAsk first / display settings reset / retained backup and Restore
