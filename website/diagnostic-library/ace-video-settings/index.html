Assetto Corsa EVO

Broken video settings / graphics startup state

PitMedic contains a dedicated diagnostic record for this problem, including the evidence required before it recommends a repair.

Automatic repair availableActiveReviewed 2026-09-01
01

How PitMedic recognizes it

Assetto Corsa EVO exits during startup or logs point to video/graphics initialization. A Video.videosettings file exists in the ACE user-data folder.

Signals PitMedic may recognize

  • Video.videosettings
  • video settings
  • graphics startup
02

Built-in response

Back up and remove only Video.videosettings so the simulator can regenerate graphics settings without wiping controls and other user data.

Repair safetyAutomatic / reversible / one-click
03
