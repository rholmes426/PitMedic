iRacing

Force feedback drops with Simucube ActivePedals and another wheelbase

For this hardware combination, iRacing documents setting simucubeTreatLinkPortAsWheel to 0 under [Force Feedback]. Close iRacing, let any update finish, and back up app.ini in Documents\iRacing. Change only the existing setting, then retest force feedback and pedal inputs in a practice session. Restore the original value with iRacing closed if it does not help.

Guided diagnosisGuidanceEvidence reviewed 2026-11-07Guide updated 2026-11-07

Checks and expected results

Check for force feedback cutting out on a rig with Simucube ActivePedals and no Simucube wheel. Confirm build 2026.11.02.01 or later and look for the existing simucubeTreatLinkPortAsWheel setting in app.ini.

Before you repair it

  • Confirm the pedals are Simucube ActivePedals and the wheelbase is from another manufacturer. Record the iRacing build and when force feedback drops.
  • Close the simulator, let any update finish, and back up Documents\iRacing\app.ini. Find simucubeTreatLinkPortAsWheel under [Force Feedback]. If the setting is missing, check the build and the active configuration file before proceeding.
  • If the current value is 1, change only that value to 0. Preserve the original value for rollback.

How to confirm the result

Repeat the same scenario in a practice session and verify steering forces and pedal inputs. If the dropout persists, close iRacing and restore the original value.

Repair limits and when to stop

Manual guidance for the specified mixed-hardware setup. Keep the original setting if you use a Simucube wheel. PitMedic does not change this setting automatically.
