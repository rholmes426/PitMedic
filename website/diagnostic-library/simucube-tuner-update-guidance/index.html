Simucube Tuner

Tuner startup GPU use, saving crashes and pedal mapping

Tuner 3.1.4 (August 20, 2026) fixes high GPU use at Windows autostart and a saving crash after a wireless wheel disconnects. 3.1.5 (September 9) fixes swapped-pedal roles lost across restarts and some input-curve mapping failures. Compare the exact symptom and supported hardware, follow Simucube's manual update instructions, and retest. Do not use True Drive recovery for Tuner.

Checks and expected results

Identify Simucube Tuner and its installed version manually. PitMedic's monitored True Drive process set is separate and does not detect or restart Tuner.

Before you repair it

  • Confirm the application is Tuner and record its version and the affected wheelbase, wireless wheel or pedals.
  • Compare the symptom with 3.1.4 or 3.1.5. Review the current supported release and preserve profiles before following vendor update instructions.
  • After the update, repeat the affected startup, save-after-disconnect or pedal-role restart scenario. Do not deliberately interrupt a firmware update.

How to confirm the result

Repeat the affected scenario after the supported update or reversible check. If it persists, preserve logs and contact the relevant vendor; this guide does not promise a successful repair.

Repair limits and when to stop

Guidance only. PitMedic does not update vendor software, flash firmware, delete profiles or change these settings automatically. An unknown version or generic failure is not proof of a match.
