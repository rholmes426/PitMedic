Le Mans Ultimate

Wheel, pedal or button configuration no longer works

PitMedic can preserve and reset only LMU's four controller configuration files when wheel, pedal or button bindings stop working.

Approval requiredActiveEvidence reviewed 2026-11-14Guide updated 2026-11-14

Checks and expected results

This is a user-selected configuration test. It does not establish that hardware, firmware or the game itself failed.

Before you repair it

  • Confirm Windows and the wheel/pedal vendor software can see the devices. Try reconnecting and rebinding before resetting.
  • Close LMU. Open its simulator page in PitMedic, choose Repair Tools, select the controls symptom and review the repair.
  • Confirm that remapping or recalibration may be required. PitMedic preserves the four named files before removing their active copies.

How to confirm the result

Start LMU, remap and calibrate where necessary, then test steering, throttle, brake and buttons. If it does not help, close LMU, choose the same item in Repair Tools and select Restore last backup. Current files are preserved before Restore.

Repair limits and when to stop

Requires PitMedic 1.0.0.12 or later. No other profile files, setups, drivers or firmware are reset. No automatic crash inference or live hardware success is claimed. Missing files alone do not prove a fault.

How PitMedic recognizes it

The user selects the matching controls symptom in Repair Tools. A crash or missing optional file alone does not trigger this reset.

Built-in response

With explicit consent, preserve and remove only direct input.json, current controls.json, keyboard.json and gamepad.json beneath UserData/player. Let LMU regenerate them, retest input, and use Restore last backup if needed.
