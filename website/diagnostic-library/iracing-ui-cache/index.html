iRacing

iRacing UI black/white screen, frozen UI, or stale Electron cache

PitMedic contains a dedicated diagnostic record for this problem, including the evidence required before it recommends a repair.

Automatic repair availableActiveReviewed 2026-09-01
01

How PitMedic recognizes it

UI process remains alive but fails to render/respond; logs point to Electron/UI state rather than simulator crash.

Signals PitMedic may recognize

  • iracing-electron
  • white screen
  • black screen
  • UI cache
02

Built-in response

Back up metadata if useful, close the UI, clear %APPDATA%\iracing-electron, then relaunch.

Repair safetyAutomatic/reversible enough for cache data; short
03

Verification sources
