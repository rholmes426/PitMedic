RaceRoom Racing Experience

Loading-screen crashes and force feedback loss after the Historic Update

RaceRoom 0.9.9.14 fixed a crash near the end of loading. Version 0.9.9.15 fixed another end-of-loading crash when joining multiplayer, along with specific wheel force feedback loss and stutter. For matching symptoms on older builds, let Steam apply the current supported update, then retry the same session and controls before resetting graphics or user profiles.

Guided diagnosisGuidanceEvidence reviewed 2026-11-07Guide updated 2026-11-07

Checks and expected results

Check the installed RaceRoom client version and whether the issue occurs at the end of loading, while joining multiplayer, or when using a wheel with a gamepad profile.

Before you repair it

  • Record the client version and whether the crash occurs at the end of loading or only when joining multiplayer. For force feedback loss, note the wheelbase and whether the active profile was created for a gamepad.
  • If the installed version predates the fix for the matching symptom, allow Steam to finish updating before testing again.
  • Keep the current graphics and controller profiles for the first retest so you can compare the same setup.

How to confirm the result

Retry the same loading or multiplayer scenario. For force feedback, confirm steering response in a practice session. If the symptom persists, save the current log and client version for further diagnosis.

Repair limits and when to stop

These fixes apply to the cases documented in the patch notes. A generic crash or force feedback dropout can have other causes.
