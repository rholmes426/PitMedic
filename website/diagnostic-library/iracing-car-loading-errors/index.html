iRacing

Loading Error 22 / 71 and damaged car content

PitMedic contains a dedicated diagnostic record for this problem, including the evidence required before it recommends a repair.

Automatic repair availableActiveReviewed 2026-09-01

How PitMedic recognizes it

iRacing reports Loading Error 22/71 or car-data corruption while other content remains available.

Signals PitMedic may recognize

  • Loading Error 22
  • Loading Error 71
  • cars.dat
  • car data

Built-in response

Prefer targeted removal of the affected vehicle folder when identifiable. If several cars are implicated, reset cars.dat/version.txt and let iRacing redownload content.

Repair safetyReversible / one-click when the affected content can be identified

Verification sources

PitMedic prioritizes vendor documentation and labels community findings separately.

  • Loading Error 22iRacing Support · Official source

    Official guidance says the error usually indicates a bad car file and recommends redownloading the affected car, then resetting cars.dat/version.txt if necessary.

    Open source
  • Loading Error 71iRacing Support · Official source

    Official guidance identifies out-of-date/corrupt car content and describes removing affected car data and car metadata.

    Open source
