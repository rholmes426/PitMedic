Assetto Corsa

Original Assetto Corsa wheel or pedals do not respond in a race

PitMedic can preserve and regenerate the original Assetto Corsa's active controls.ini when the wheel or pedals work in configuration menus but not in a race.

Approval requiredActiveEvidence reviewed 2026-11-17Guide updated 2026-11-17

Checks and expected results

Try device detection, the correct saved preset and reassignment first. A reset is an optional, consented configuration test rather than proof that the hardware failed.

Before you repair it

  • Confirm Windows and the vendor software see the wheel and pedals. Select or reapply the intended preset before resetting.
  • Close the race process, original launcher and Content Manager. Open the original Assetto Corsa page in PitMedic and choose Repair Tools.
  • Review the controls reset and its remapping/calibration warning. Only the active cfg/controls.ini is preserved and removed.

How to confirm the result

Reassign steering, pedals and buttons, verify axis direction and test a stock practice session. If the test fails, close configuration tools and use Restore last backup; current data is preserved first.

Repair limits and when to stop

Requires PitMedic 1.0.0.13 or later. Does not delete saved control presets, car setups, mods, firmware or drivers. Content Manager may reapply a preset, so avoid concurrent edits. Live wheel compatibility still needs a functional retest.

How PitMedic recognizes it

An exact current-session controls.ini failure, or an explicit controls-symptom selection in Repair Tools. Missing inputs alone do not establish damaged settings.

Built-in response

After consent and with the simulator, launcher and Content Manager closed, preserve only Documents/Assetto Corsa/cfg/controls.ini and remove its active copy. Remap and recalibrate in AC or Content Manager, retest, and use Restore last backup if ineffective. Saved controller presets, car setups, mods and other configuration files are preserved.

Repair safetyAsk first / active bindings and calibration reset / retained backup and Restore
