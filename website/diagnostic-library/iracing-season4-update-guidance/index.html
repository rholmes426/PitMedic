iRacing

Reference Car Input display and spotter audio fixes

2026 Season 4 Patch 1 (build 2026.10.01.01) fixes Reference Car Input display problems with foveated quad views or triple screens and spotter audio stopping. For these symptoms on older builds, use the supported updater and retest before resetting renderer or audio settings. Let updates finish; preserve unrelated crash evidence.

Compare the iRacing build and exact display/audio symptom. These patch notes do not provide a crash signature.

Before you repair it

  • Record the build, display configuration and whether Reference Car Input or the spotter is affected.
  • For an older build, let the official updater complete before repair or retest. Unknown build numbers do not prove that a fix is missing.
  • Retry the same display or spotter scenario. Preserve logs if it persists on the supported build instead of repeatedly resetting configuration.

How to confirm the result

Repeat the affected scenario after the supported update or reversible check. If it persists, preserve logs and contact the relevant vendor; this guide does not promise a successful repair.

Repair limits and when to stop

Guidance only. PitMedic does not update vendor software, flash firmware, delete profiles or change these settings automatically. An unknown version or generic failure is not proof of a match.
