Assetto Corsa EVO

Corrupt ACE user profile / launch state

PitMedic contains a dedicated diagnostic record for this problem, including the evidence required before it recommends a repair.

Approval requiredActiveReviewed 2026-09-01
01

How PitMedic recognizes it

Repeated early launch crash or black/white startup failure without a stronger hardware/driver signature after a targeted video reset is not enough.

Signals PitMedic may recognize

  • ACE folder
  • Saved Games\ACE
  • Documents\ACE
  • profile corruption
02

Built-in response

Preserve the ACE user-data folder, move the active copy aside, and allow Assetto Corsa EVO to build a clean profile on the next launch.

Repair safetySignificant / reversible / ask first
03
