Assetto Corsa EVO

Corrupt ACE user profile / launch state

A clean Assetto Corsa EVO profile is a last diagnostic step when current evidence points to configuration corruption and narrower repairs have not helped.

Approval requiredActiveEvidence reviewed 2026-09-01Guide updated 2026-09-29

Checks and expected results

Before you repair it

  • Identify the repeated startup failure and record which targeted cache, display, or controller repairs have already been tried.
  • Locate the ACE user-data folder in the actual user profile, including any redirected Documents location.
  • Close Assetto Corsa EVO and preserve the complete affected data before approving a move of the active copy.

How to confirm the result

Relaunch Assetto Corsa EVO to create clean user data, review graphics and controls, and retry the original failure. If it works, bring back personal data selectively; if it fails, restore the preserved profile with the simulator closed.

Repair limits and when to stop

A new profile can reset preferences and bindings or temporarily hide saved data. It is not a repair for driver, hardware, or game-package faults. Do not delete the backup or copy all of the old configuration back before retesting.

How PitMedic recognizes it

Repeated early launch crash or black/white startup failure without a stronger hardware/driver signature after a targeted video reset is not enough.

Signals PitMedic may recognize

  • ACE folder
  • Saved Games\ACE
  • Documents\ACE
  • profile corruption

Built-in response

Preserve the ACE user-data folder, move the active copy aside, and allow Assetto Corsa EVO to build a clean profile on the next launch.

Repair safetySignificant / reversible / ask first
