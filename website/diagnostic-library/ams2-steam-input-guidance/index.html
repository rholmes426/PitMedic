Diagnostic guidance

Automobilista 2

Wheel or paddles stop responding: Steam Input check

A Reiza staff response on September 20, 2026 recommends disabling Steam Input for AMS2 when a wheel or paddles stop working. Record the prior per-game setting, close AMS2, test the AMS2-only override, then retest steering and paddles. Restore the prior setting if ineffective. Do not change the global Steam setting or apply this automatically to gamepads. The thread does not confirm success on the original poster's PC.

Guided diagnosisGuidanceEvidence reviewed 2026-10-05Guide updated 2026-10-05

Checks and expected results

Manual check for a wheel/paddle input problem; not a generic crash diagnosis or an automatic setting change.

Before you repair it

  • Confirm the wheel and paddles register in the vendor software, and note the current AMS2 bindings.
  • In Steam Library, open Automobilista 2 > Properties > Controller. Record the existing override before testing Disable Steam Input for this game.
  • Start AMS2 and test steering plus both paddles. If it does not help, restore the recorded override before investigating controller-file damage.

How to confirm the result

Repeat the affected scenario after the supported update or reversible check. If it persists, preserve logs and contact the relevant vendor; this guide does not promise a successful repair.

Repair limits and when to stop

Guidance only. PitMedic does not update vendor software, flash firmware, delete profiles or change these settings automatically. An unknown version or generic failure is not proof of a match.
