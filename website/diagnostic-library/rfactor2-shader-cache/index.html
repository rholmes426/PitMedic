rFactor 2 black track surfaces or rendering glitches

If a track repeatedly loads with black surfaces, dark boxes or other rendering artifacts, a rebuild of the generated shader and track caches is worth trying.

Approval requiredActiveEvidence reviewed 2026-11-21Guide updated 2026-11-21

Checks and expected results

Studio 397 has documented clearing these caches for specific rendering artifacts. The same symptom can also come from a car or track mod, display configuration, or the graphics driver.

Before you repair it

  • Test the same symptom on a stock track and car. If only one mod shows the problem, check for an update to that content.
  • Close rFactor 2, Mod Mode and Dedicated Server, and let any Steam update finish before opening Repair Tools.

How to confirm the result

Choose Rebuild shader and track caches and approve. Start the simulator and retry the same track. The first load can take longer. If the issue persists, close the simulator and choose Restore last backup for this repair.

Repair limits and when to stop

PitMedic only backs up and clears recognized .rrshd and .cbash files in the respective Shaders and CBash folders under UserData\Log. It leaves trace logs, graphics settings and installed content alone. If the recognized files are absent, PitMedic stops without changing anything.

Manual steps without PitMedic

Use the generated-cache locations documented by Studio 397.

  1. With the game and tools closed, use Steam to browse the local rFactor 2 installation.
  2. Open UserData\Log. Move .rrshd files from Shaders and .cbash files from CBash into separate backup folders. Keep the original directories.
  3. Relaunch and retry the same track. To undo the change, close the simulator before restoring the backed-up files to their original folders.

When to use this check

Choose Rebuild shader and track caches in Repair Tools for repeatable graphical artifacts, such as black track surfaces, that may be related to the generated cache.

Built-in response

With rFactor 2 and its tools closed, preserve and clear only recognized .rrshd and .cbash files in the corresponding cache directories. Relaunch to rebuild and retest the same track. Restore last backup is available.
