Loading Error 63 while loading a spotter sound

Loading Error 63 identifies a spotter-sound load problem. PitMedic offers the vendor-documented app.ini regeneration procedure.

Approval requiredActiveEvidence reviewed 2026-11-14Guide updated 2026-11-14

Checks and expected results

A custom spotter pack may be broken, but Error 63 alone does not identify a file to delete. The recovery preserves app.ini so it can be restored.

Before you repair it

  • Confirm the exact Loading Error 63. Other loading-error numbers use different repair paths.
  • Close iRacing and let updates finish. In Repair Tools, choose Loading Error 63 and review the settings-reset warning.
  • PitMedic preserves app.ini and removes only that active file. Setups, replays, paints and spotter packages remain in place.

How to confirm the result

Start the same car/session and test the spotter. Some application settings may need to be re-entered. If ineffective, close iRacing and use Restore last backup for this repair; the regenerated file is preserved first.

Repair limits and when to stop

Requires PitMedic 1.0.0.12 or later. This does not delete custom spotter packs or reinstall iRacing. Successful file regeneration does not prove every sound pack works.

How PitMedic recognizes it

Exact Loading Error 63 in current evidence, or the user selecting that error in Repair Tools.

Signals PitMedic may recognize

  • PitMedic diagnostic signature: loading-error-63

Built-in response

With explicit consent, preserve app.ini and remove only its active copy so iRacing can regenerate it. Application preferences may reset. Setups, paints, replays and spotter packages remain in place. Retest and use Restore last backup if ineffective.
