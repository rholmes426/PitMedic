Diagnostic guidance

Windows

Check Windows system file integrity

If several applications or Windows itself fail repeatedly, Windows integrity verification can provide the next evidence.

Guided diagnosisGuidanceEvidence reviewed 2026-11-26Guide updated 2026-11-26

Checks and expected results

PitMedic can request the Windows component-store scan and protected-file verification without asking Windows to restore files.

Before you repair it

  • Close running simulators and let active updates finish.
  • Choose Check Windows system files under Home → Windows repair tools, review the estimate and approve the diagnostic.

How to confirm the result

Review the saved windows-integrity-results.txt output after both commands finish. Choose the repair only if the findings support it.

Repair limits and when to stop

An ordinary app crash or access violation alone does not establish corruption. A completed scan is a diagnostic result.

When to consider this guidance

Use Home, Windows repair tools to request system integrity verification when Windows components or multiple apps exhibit repeatable failures.

Suggested manual checks

With approval, run DISM ScanHealth and SFC verifyonly. Review the saved output before selecting a repair. A completed command alone does not diagnose corruption.
