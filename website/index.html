How it works

Monitor

Tracks supported simulators in real time for application errors, log events, and system health issues.

Explain

Connects the evidence and tells you what happened in language that makes sense.

Repair

Completes many known fixes automatically with one click, creating a backup and a clear record of every change.

About the project

A community project for the
sim-racing community.

PitMedic is built because troubleshooting a broken sim session shouldn't require hours of searching. The code is public, and useful feedback is always welcome.
