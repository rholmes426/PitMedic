How it works

Technical problems.
Straightforward help.

Let PitMedic run while you race. If something goes wrong, the evidence and available repair options are in one place.

Race as usual.

PitMedic monitors supported simulators for application errors, log events, and system health issues.

Understand the problem.

See what the evidence points to, explained in plain language, with a clear next step.

Repair with confidence.

Run a supported fix with one click. File-changing repairs preserve recovery data, and PitMedic records what it does.

About the project

Made by a sim racer.
Built for all of us.

PitMedic is built because troubleshooting a broken sim session shouldn't require hours of searching. It runs locally, keeps repairs explained and reversible, and stays free and open source. The code is public, and useful feedback is always welcome.
