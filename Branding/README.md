# PitMedic racing-line identity

Approved racing-line P in navy, white and orange. Generated with the built-in
image tool from the approved concept; these are raster masters, not vector files.

- Icon: white/orange P on an opaque navy square. No simulated transparency.
- Wordmark: navy/orange mark and PitMedic lettering on white.
- App: shared PNG and multi-resolution ICO in Source/PitMedic/Assets.
- Web: versioned icon, favicon, touch icon and wordmark in website/assets/brand.

Final generation instructions: preserve the approved P geometry and orange
connection; remove the presentation board; produce a single icon on solid navy
and a separate horizontal wordmark on white. Export icon sizes without changing
the artwork. Existing signed installers retain their original embedded icons.
