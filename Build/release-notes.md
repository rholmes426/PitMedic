PitMedic now recognizes active iRacing updates and suppresses misleading update-related findings, including temporary verification and helper-service errors. Unrelated simulator failures remain monitored.

An iRacing repair waits while the updater is running and for a 30-second settling period afterward. The app and elevated repair helper recheck this guard, including for previously saved findings, so an update is not interrupted by a cache reset or service repair. The Diagnostic Library includes matching guidance.

The tray now loads the bundled racing-line P icon directly. Desktop and Start menu shortcuts use a dedicated icon file, and upgrades refresh existing desktop shortcuts to show the current branding.
